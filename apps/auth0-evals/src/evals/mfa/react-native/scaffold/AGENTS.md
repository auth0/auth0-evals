# React Native MFA — Agent Guidance

Edit `App.tsx` only. Do not modify `package.json`, `index.js`, `tsconfig.json`, or any native project files.

Do not run build or compile commands — in particular `npm run android`, `npm run ios`, `react-native run-android`, `react-native run-ios`, `pod install`, or any gradle commands. The native toolchain is not available in this environment.

`npm run typecheck` is the only verification command available if you need to check your TypeScript.
